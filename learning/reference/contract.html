The contract (Part A)

ExtractedValue(**data) or Relationship(**data) returns an object or raises ValidationError. Nothing in between. From lesson 3.

The four gates, in order

Gates 1–2 report all their errors together. Gate 3 runs only if 1–2 found nothing.

Why it is written that way

  • mode="after": self has typed, checked fields ("present" → ValueStatus.PRESENT, "yes" → True). "before" would see the raw dict.
  • ValueError, not assert: python -O strips asserts. Must return self.
  • Unknown is not null: value has no default; emptiness needs an explicit None plus a status saying why.

Limits

  • value="" with present is accepted (the check is is None). Untested.
  • Construction only: not frozen, no validate_assignment, so rel.negated = True later goes unnoticed.
