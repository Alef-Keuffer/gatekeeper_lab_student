# Mission: Own the Gatekeeper solution

## Why
The whole Gatekeeper lab solution (Parts A–E, `tests/test_extra.py`, `REFLECTION.md`) was generated by Claude Code. I want to own it: explain and justify every line to the professor in a defense or Q&A, so the submission is honestly mine.

## Success looks like
- Walk through the pipeline (contract → checks → report → `decide()` → disposition) in under two minutes, without notes.
- For any function in `gatekeeper.py`: say what it does, why it is written that way, and which test pins it.
- Predict `decide()`'s disposition for any report and consequence, and name the rule that fired.
- Defend the non-obvious choices when probed: the `end_offset` bound in `verify_span`, regex alternation order and `\b`, `casefold()`, `NO_MATCH` vs `NOT_FOUND_IN_SOURCE`, never reading `uncertainty`.
- Name the solution's weaknesses before being asked: `decide()` fails open, the negation cues miss `didn't`/`nonsignificant`, hedges and wrong-but-valid ids pass, and `human_review_completed` is a bare boolean.
- Answer the four `REFLECTION.md` questions in my own words.

## Constraints
- Solid Python; new to pydantic v2.
- Lessons in English, short, one win each.
- Defense date and format: unknown so far (see NOTES.md).

## Out of scope
